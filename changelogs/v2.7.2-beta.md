# AndroidIDE Ultra Version v2.7.2-beta Changelog

This release includes internal build system improvements and maintenance.

## Important notes

- The project name in `settings.gradle.kts` has been updated to `AndroidIDE-Ultra` to comply with Gradle's naming conventions for type-safe project accessors.

## Improvements

- **Build System**: Enabled non-transitive R classes (`android.nonTransitiveRClass=true`) to improve build speeds and reduce APK size.
- **Gradle Compatibility**: Fixed project naming to support Type-Safe Project Accessors.
- **Setup Script**: Updated `idesetup.sh` with correct manifest URLs and enhanced visual feedback.
- **Documentation**: Modernized `CONTRIBUTING.md` with updated Android Studio and JDK requirements.

We believe that you'll have a delightful experience using AndroidIDE Ultra v2.7.2-beta!
