# AndroidIDE Ultra

**AndroidIDE Ultra** is an enhanced, community-driven fork of the original [AndroidIDE](https://github.com/AndroidIDEOfficial/AndroidIDE) project. It is an Integrated Development Environment (IDE) for developing real, Gradle-based Android applications directly on Android devices.

---

## 📢 Important Notice
This project is a fork of the original AndroidIDE project, which is no longer maintained by its original authors. **AndroidIDE Ultra** aims to continue the legacy by providing updates, bug fixes, and new features.

---

## ✨ Features
- **Full Gradle Support**: Build real Android apps with the power of Gradle.
- **Modern JDKs**: Support for JDK 11 and JDK 17.
- **Terminal Emulator**: Integrated terminal with essential packages.
- **SDK Manager**: Manage Android SDKs directly from the terminal.
- **Real-time Log Reader**: Monitor your app's logs as they happen.
- **Language Servers**: Support for Java and XML (Kotlin support in progress).
- **UI Designer**: Drag-and-drop interface for layout design.
- **Git Integration**: Built-in Git support for version control.

## 🚀 Improvements in Ultra
- **Updated Branding**: Refreshed identity as AndroidIDE Ultra.
- **Community Focused**: Open for contributions and active maintenance.
- *(More improvements coming soon...)*
